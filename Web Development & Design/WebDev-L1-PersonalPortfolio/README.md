# Personal Portfolio Website

A responsive, multi-section personal portfolio website designed and developed as part of the Web Development & Designing Internship at Oasis Infobyte (Level 1 - Task 2).

## 📌 Project Overview
This project serves as a modern digital resume showcasing technical skills, featured projects, background information, and personal contact details[cite: 1]. It provides a smooth navigation experience across all sections and adapts fluidly to desktop and mobile displays[cite: 1].

## 🚀 Key Features
* **Navigation Bar:** Fixed navbar with smooth scrolling to sections (`About`, `Skills`, `Projects`, `Contact`)[cite: 1].
* **Hero/Profile Section:** Features personal name, professional title, and a modern avatar placeholder[cite: 1].
* **About Me:** Highlights personal background, learning journey, and web development interests[cite: 1].
* **Skills Section:** A styled visual grid displaying foundational technical competencies[cite: 1].
* **Projects Grid:** Project cards showcasing featured work with links to GitHub repositories[cite: 1].
* **Contact & Footer:** Professional contact information along with social media profile placeholders[cite: 1].
* **Fully Responsive Layout:** Designed using modern CSS flexbox and grid techniques to ensure mobile compatibility[cite: 1].

## 🛠️ Tech Stack
* **HTML5:** Semantic structural layout[cite: 1]
* **CSS3:** Custom styles, CSS grid/flexbox layouts, smooth scrolling, and mobile media queries[cite: 1]
