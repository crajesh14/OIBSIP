# Temperature Converter Website

An interactive web tool built for converting temperature values simultaneously between Celsius, Fahrenheit, and Kelvin with real-time validation and edge-case handling (Oasis Infobyte Internship - Level 1 Task 3)[cite: 1].

## 📌 Features
* **Multi-Unit Output:** Converts input to Celsius, Fahrenheit, and Kelvin at once[cite: 1].
* **Input Validation:** Rejects empty or non-numeric inputs with clear user error messages[cite: 1].
* **Absolute Zero Prevention:** Displays friendly error notices if inputs fall below absolute zero ($-273.15^\circ\text{C}$)[cite: 1].
* **Clean UI Layout:** Designed using simple, modern CSS box models and clean typography[cite: 1].

## 🛠️ Tech Stack
* **HTML5:** Semantic form inputs and selector controls[cite: 1]
* **CSS3:** Flexbox layout and state-driven error styling[cite: 1]
* **Vanilla JavaScript:** Conversion formulas and DOM manipulation[cite: 1]
